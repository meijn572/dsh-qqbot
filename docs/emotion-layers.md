# 情绪分层：即时、每日、长期

状态：情绪层第一版已实现；日记和人格消费未改。

## 1. 结论

情绪系统分三层：

```text
5 分钟复盘     即时情绪事件 + 当前波动
日记           每天整理，写成叙事
人格板块       长期稳定结论
```

另外保留：

```text
set_emotion    强情绪即时记录
```

不再保留：

```text
3–5 小时情绪自检
```

## 2. 为什么要分层

现在的 3–5 小时自检同时想干三件事：

```text
记录这一轮发生了什么
更新当前心情
总结长期感受
```

结果每一件都不够好：

- 不够及时
- 只看最近一批 L0，容易错过具体回合
- 长期总结又和人格板块重叠

拆开之后：

```text
分钟级：情绪事件
天级：叙事整理
月级：人格结论
```

## 3. 第一层：5 分钟复盘

### 触发

```text
最后一条消息后 5 分钟没有新消息
且这段对话有新的完整回合
```

不是每轮都跑。

连续聊天时先不跑，等真正空闲。

### 输入

```text
这一轮用户说了什么
她怎么回
最近 2–3 轮上下文
```

不要塞 40 条 L0。

### 输出

```json
{
  "label": "心动又警惕",
  "valence": 0.5,
  "arousal": 0.4,
  "reason": "他把一句歌词说成是自己的话，递过来的时候我有点接不住"
}
```

没有明显情绪：

```json
{"skip": true}
```

### 写入

```text
emotion_recent += 一条
source = idle-review
```

可选：

```text
更新当前 valence / arousal
```

### 去重

```text
同一轮已经由 set_emotion 记过
→ 5 分钟复盘不要重复写
```

### 定位

```text
只负责即时波动
不写长期人格
不写关系结论
```

## 4. 第二层：日记

### 现状

`qqbot/domains/growth/diary.py`：

```text
每天 23 点后
有素材才写
第一人称日记
写入 diary 表
```

输入：

```text
当天 L0
当天活动
人格
相关旧记忆
```

### 改造方向

输入增加：

```text
当天 emotion_recent
```

输出：

```text
第一人称日记
自然带出“今天的心情线”
```

不是：

```text
逐条列情绪标签
输出 JSON
更新人格
```

### prompt 约束

```text
如果今天有情绪事件，不要把标签逐条列出来。
写成一两条自然的感受线：
什么事、当时什么感觉、后来怎么落下。
```

### 日记负责

```text
当天发生了什么
哪些事让我起了情绪
这些情绪后来怎么落下
今天整体是什么感觉
```

### 日记不负责

```text
我越来越依赖他
我变成了一个更柔软的人
关系进入依赖期
```

这些是人格/关系结论。

### 定位

```text
天级叙事整理
不是情绪状态表
不是人格写入器
```

## 5. 第三层：人格板块

### 输入

```text
日记
情绪事件
关系变化
```

### 输出

```text
稳定自我认知
关系叙事
长期结论
```

### 边界

```text
人格结论只能由人格板块写
情绪层和日记都不能直接改人格
```

### 定位

```text
月级稳定结论
```

## 6. 强情绪即时记录

保留：

```text
set_emotion
```

适用：

```text
明显被戳到
当下情绪很强
模型自己判断需要立即记
```

它不承担普通情绪记录。

普通情绪交给 5 分钟复盘。

## 7. 数据流

```text
对话
  ↓
5 分钟复盘
  ↓
emotion_recent + 当前 state
  ↓
当天日记
  ↓
人格板块长期演化
```

强情绪可以旁路：

```text
对话
  ↓
set_emotion
  ↓
emotion_recent + 当前 state
```

## 8. 写入者

```text
情绪事件：5 分钟复盘、set_emotion
当前状态：5 分钟复盘、set_emotion
日记：日记任务
人格：人格演化
```

一个层只有一个主要写入者。

不要：

```text
5 分钟复盘也写人格
日记也写关系阶段
情绪自检也写长期结论
```

## 9. 去掉 3–5 小时自检

原因：

```text
即时性不如 5 分钟复盘
长期性不如日记 + 人格
定位重复
```

保留它只会造成：

```text
重复写事件
状态被多次覆盖
日志来源混乱
```

## 10. 还没定的问题

### 10.1 5 分钟复盘要不要更新 state

方案 A：

```text
只写 emotion_recent
state 不变
```

更稳，但当前回答不会立刻变。

方案 B：

```text
同时小幅更新 state
```

更实时，但可能情绪抖动。

### 10.2 5 分钟从哪一刻算

```text
最后一条 assistant 消息后
还是最后一条用户消息后
```

建议：

```text
最后一条消息后
```

包括用户没回的情况。

### 10.3 连续聊天怎么合并

```text
每 5 分钟空闲只复盘一个窗口
窗口内多轮合并成一条
```

不要每轮各写一条。

### 10.4 日记 23 点后漏内容

当前 23 点写当天。

23 点后还在聊，会漏。

候选：

```text
凌晨写前一天
或 23 点后内容算第二天
```

### 10.5 人格怎么消费日记

建议：

```text
人格演化读取日记和情绪事件
但不直接由日记触发写入
```

避免日记变成人格写入器。

## 11. 非目标

```text
不把 5 分钟复盘做成长期人格总结
不让日记直接改 self_model
不让情绪层写关系阶段
不保留 3–5 小时自检
不在预检里加情绪字段
```

## 12. 一句话

```text
情绪管分钟
日记管天
人格管月
```

各自只写自己那一层。

## 13. 第一版实现

### 代码

```text
bridge.py
  emotion_idle_loop

qqbot/domains/growth/emotion.py
  review_turn
  parse_emotion
```

### 触发

```text
主人私聊最后一条消息后空闲 5 分钟
检查间隔 30 秒
只看未复盘的新消息
```

配置：

```yaml
emotion_idle:
  enabled: true
  idle_seconds: 300
  interval_seconds: 30
  max_messages: 8
```

### 输入

```text
最近最多 8 条
用户：...
洄：...
```

不读 40 条 L0，不读人格块。

### 输出

```json
{
  "label": "心动又警惕",
  "valence": 0.5,
  "arousal": 0.4,
  "reason": "..."
}
```

写入：

```text
source = idle-review
```

### 去重

```text
reviewed[chat_key] = 已复盘的最后一个 bridge seq
同一 bridge 进程内不重复
bridge 重启后 run_id 重置
```

强情绪工具已经在窗口内记过：

```text
source = self 且 ts >= window_start
→ 跳过本轮复盘
```

### 已移除

```text
3–5 小时情绪自检
emotion_check_loop
```

### 还没做

```text
日记读取 emotion_recent
人格消费日记
预检情绪字段
```
