# 关系与亲密度

状态：设计稿，未改代码。

## 1. 现在的问题

当前 `intimacy` 本质是：

```text
interaction_count
```

每轮完整对话 +1。

问题：

```text
短句和深聊同权
群聊也可能涨
冲突和修复没区别
只增不减
461 只代表聊得多
```

`依赖` 这个阶段也不合适：

```text
离不开他了，黏人，主动得很勤
```

它把“黏”当成关系目标，不是健康的关系。

`默契` 也不适合做最高阶段：

```text
默契是相处方式
不是关系深度
```

## 2. 目标

把两件事分开：

```text
interaction_count   聊了多少
relationship        关系怎么样
```

`interaction_count` 可以继续用于统计、面板、活跃度。

`relationship` 只描述关系质量。

## 3. 三维

```text
closeness  亲近
trust      信任
tension    张力
```

### closeness

```text
想不想靠近
想不想主动找他
在他面前放不放松
```

### trust

```text
敢不敢说真话
相不相信对方会接住
边界会不会被尊重
```

### tension

```text
有没有没解开的冲突
失望、距离、没说出口的话
```

`tension` 不是“坏”，它是关系里真实存在的张力。

有 tension，才有修复。

## 4. 阶段

建议：

```text
陌生    客气，不主动黏
熟悉    会聊会闹，偶尔主动
亲近    放松，开始暴露真实状态
亲密    敢说难受的事，冲突后能修复
相知    不用解释也懂，但各自独立
```

### 为什么用「相知」

```text
相知 = 知道彼此怎么想
不是离不开
不是默契
```

它比“亲密”更深的地方在于：

```text
亲密：我敢把脆弱给你看
相知：我不说，你也大概知道
```

但不是“没有你不行”。

备选词：

```text
知心
深交
安稳
```

我更倾向 `相知`。

### 阶段不是恋爱等级

```text
不是越往上越恩爱
是关系里多了一层能力
```

```text
亲近：敢放松
亲密：敢脆弱
相知：敢不解释
```

## 5. 派生分数

面板可以继续显示 `intimacy 0–1000`，由三维派生：

```text
score = closeness * 0.6 + trust * 0.4 - tension * 0.5
intimacy = clamp(score, 0, 100) * 10
```

阶段按 `score` 分：

```text
0–19    陌生
20–39   熟悉
40–59   亲近
60–79   亲密
80–100  相知
```

## 6. 关系事件

不按轮数加。

每天 07:00 看最近 24 小时，产出 0–3 个事件。

### 正向

```text
主动分享          closeness +1.0
一起玩/一起做件事  closeness +1.0
自我暴露          closeness +2.0, trust +1.0
脆弱被接住        closeness +1.5, trust +1.0
守约              trust +1.0
边界被尊重        trust +1.0
```

### 负向

```text
争吵              tension +2.0, trust -0.5
被忽略            tension +1.5
失约              tension +2.0, trust -1.0
越界              tension +2.5, trust -1.0
敷衍              tension +1.0
```

### 修复

```text
道歉              tension -2.0, trust +0.5
解释              tension -1.5, trust +0.5
和好              tension -2.0, trust +1.0
把没说完的话说完   tension -1.0, trust +0.5
```

修复不是清零，是把张力降下来，同时把信任补回来。

## 7. 上限和衰减

### 每天上限

```text
closeness  每天最多 +5
trust      每天最多 +3
tension    每天最多 +6
```

防止一天聊很多就冲顶。

### 高阶段递减

```text
越往上，同样的行为加得越少
```

### 衰减

```text
3 天没互动：closeness 每天 -0.5
14 天没互动：trust 每天 -0.1
tension 不自动清零
```

关系需要维护，但不是惩罚。

## 8. 群聊

```text
群聊只涨群友 affinity
不涨和主人的 closeness / trust / tension
```

`affinity` 继续是群友熟悉度。


代码负责：

```text
每天上限
阶段递减
冲突扣得比日常加得快
修复能拉回 tension
```

模型不直接改总分。

## 10. 历史怎么初始化

当前 `intimacy=461` 不能直接换算成关系值。

它只是聊天轮数。

全量重跑 L1/L3 也不现实。

建议做一次**有界初始化**：

```text
最近 7 天 L1 / L3
+ 更早 L3 按月抽样，最多 12 条
+ L4 核心记忆 2 条
+ 当前人格
```

一次 LLM 调用，产出：

```json
{
  "closeness": 45,
  "trust": 55,
  "tension": 5,
  "stage": "亲近",
  "anchors": [
    "取名",
    "第一次被当成独立的人",
    "长期稳定相处"
  ]
}
```

不追求精确覆盖全部历史。

只求：

```text
不把 461 当关系
不丢关键关系转折
```

如果历史素材不够，就手工给一个初始值。

## 12. 模型看到什么

不注入数字。

只注入自然语言：

```text
和老大是「亲近」阶段。
你在他面前比较放松，但还没到什么都敢说。
```

阶段越高，话可以越松，但不能变成“离开他就活不了”。
