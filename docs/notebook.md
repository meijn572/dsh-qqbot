## 1. 它是什么

小本子不是“记忆管理页”。

记忆页是系统视角：

```text
L0 / L1 / L3 / L4
source_ids
memory_links
thread_status
```

小本子是她自己的视角：

```text
我还惦记着什么
我想记一句什么
我想让主人做什么
今天我是怎么过的
```

## 2. 四块内容

### 还没完的事

来源：open L3。

```text
标题
一句话状态
最后提及
```

只读，不在这里编辑。

作用：

```text
让她一眼看到还有什么没结束
也让主人知道她心里挂着什么
```

不展示：

```text
source_ids
memory_links
证据
技术状态
```

### 便签

来源：`notes`。

她自己写的一句话。

```text
今天发生的一件事
主人说过的一句话
她自己的一点情绪
一个突然想到的念头
```

工具：`write_note`。

### 任务

来源：`tasks`。

她派给主人的事。

```text
早点睡
记得吃饭
别老坐着
```

工具：`create_task` / `complete_task`。

### 日记

来源：`diary`。

每天 23:00 自动写的整篇。

工具：`read_diary`。

## 3. 和记忆的边界

```text
L3 open        → 小本子的“还没完的事”
L1 / L3 / L4   → 记忆页
notes          → 小本子的“便签”
tasks          → 小本子的“任务”
diary          → 小本子的“日记”
```

小本子不复制记忆正文。

只借用 L3 的：

```text
标题
状态
最后提及
```
