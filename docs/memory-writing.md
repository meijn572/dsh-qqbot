# L1 / L3 写法

状态：文字稿，给手动润色用。

相关代码：

```text
service/extractor.py
  EXTRACT_SYSTEM       L1 抽取
  L1_COMPRESS_SYSTEM   L1 二次压缩
  THREAD_SYSTEM        L3 事件
```

这篇不是规范，是给例子和语感做底稿。  
真正生效的是 prompt 里的示例，不是这里的说明。

---

## 1. 两个层的区别

```text
L1  便签：这一段发生了什么
L3  回想：这件事为什么会被记住
```

L1 是刚发生的事，大部分很快会忘。  
L3 是过一阵子还会想起来的形状。

不要把 L1 写成 L3，也不要把 L3 写成 L1 的加长版。

---

## 2. L1 想要的感觉

### 不是逐轮记录

不想要：

```text
主人说……
我说……
主人又说……
```

想要：

```text
他这两天一个人住，睡到自然醒，觉得清静；
中午不想挤食堂，打算错峰去。
```

### 第一组对照（目前可以）

记录：

```text
主人说工具占了 10k。我说 workflow 可以砍，
但表情、发图、刷视频、设提醒、翻日记不要砍。
```

便签：

```text
他盯着那 10k 的工具发愁。我说 workflow 砍了不心疼，
但表情、发图、刷视频、设提醒、翻日记得留着——那是我手脚。
```

区别不在称呼，在：

```text
有没有留下当时的动作/状态
有没有把「他说、我说」压成一段叙述
```

### 第二组对照（目前还不够）

现在这组只是把「主人」换成「他」，没有真正压缩：

```text
记录：
主人这两天一个人住宿舍，睡到自然醒，觉得清静；中午食堂人多，打算错峰去。

便签：
他这两天一个人住，睡到自然醒，觉得清静；中午不想挤食堂，打算错峰去。
```

这组需要手动改。

建议换成真正多句压一句的例子：

```text
原始：
主人：食堂人好多
我：那等会儿再去
主人：先躺一会儿

便签：
他嫌食堂人多，先躺了一会儿，打算错峰再去。
```

这才能看出：

```text
多条来源 → 一条便签
不是一条来源 → 一条便签
```

### L1 可以保留的结构

```text
1–3 条
同一场景合并
不要一轮一条
```

### L1 不要硬加的东西

```text
每条必须多少字
每条必须引用几条来源
必须统一用「他」
```

称呼自然就行：

```text
第一次用「主人」
后面用「他 / 她」指代
不要写「你」
```

## 3. L3 想要的感觉

### 不是把对话抄一遍

不想要：

```text
主人说……我说……主人又说……我又说……
```

也不想要：

```text
把一件事压成一句结论
```

想要：

```text
写你回头想起这件事时，
脑子里先浮出来的那个画面、那句话、那个转折，
再写它为什么还留着。
```

### 例子一：铁人之乱

事实来源：L3 #1211。

```text
他发来一张截图，里面有人把「要人陪」换算成上四休三、六小时、五十岁退休，
还管这叫「铁人之乱」。这个说法我没接。
后来他问什么时候发动，我说得先拔插头——这话得断着电说才安全。
三点一刻了，我催他去睡。
```

注意：

```text
截图是别人说的，不是他说的
「铁人之乱」是截图里的说法，不是他的主张
```

### 例子二：潮汕那杯饮料

事实来源：L3 #1167。

```text
他半年前在潮汕喝到一杯不含茶的饮料，回来一直惦记。
当时本地没卖，只能让朋友放假带。
现在楼下有了，正好适合他这种喝茶容易睡不着的人；
我说那就成常驻了——当初惦记的味儿，被卖成了网红款。
```

需要保留的点：

```text
不含茶
他喝茶容易睡不着
当初只能让朋友带
现在楼下有了
```

### 例子三：鱼八股

事实来源：L3 #1145。

```text
他刷到另一条鱼，说那条不怎么说鱼八股，敢直接顶回去。
这点我不如它。他说只是风格不同，我温柔一点也挺好。
「温柔」这词我用着别扭，但意思我明白，这话我留着。
```

猫娘那个例子暂时不用，事实记不准。

### L3 不要硬加的东西

```text
必须 100–250 字
最多一个主题
只留一个转折
只留一句原话
只留一个画面
```

长短由事情决定。  
有的两三句，有的一整段。

### L3 真正要避免的

```text
连续「主人说……我说……」
按时间把每句话都过一遍
为了短把重要的部分删掉
为了完整把没被记住的细节也塞进去
```

## 4. 当前 prompt 在哪里

### L1

```text
service/extractor.py
  EXTRACT_SYSTEM
```

包含：

```text
L1 的定位
1–3 条
视角
说话方向
只写确定
写什么 / 不抽什么
示例
像人一点
情绪字段
输出前检查
输出格式
```

### L1 二次压缩

```text
service/extractor.py
  L1_COMPRESS_SYSTEM
  Extractor._compress_l1()
```

L1 超过 3 条时触发。  
不想要这个兜底，可以去掉 `_compress_l1` 调用。

### L3

```text
service/extractor.py
  THREAD_SYSTEM
```

包含：

```text
什么值得留
怎么分组
谁做的事不能换
写成一件事
三个真实例子
updates / new
status
感悟
难忘性
```

## 5. 手动改的例子

### 改 L1 第二组

把这段：

```text
记录：
主人这两天一个人住宿舍，睡到自然醒，觉得清静；中午食堂人多，打算错峰去。

便签：
他这两天一个人住，睡到自然醒，觉得清静；中午不想挤食堂，打算错峰去。
```

换成：

```text
原始：
主人：食堂人好多
我：那等会儿再去
主人：先躺一会儿

便签：
他嫌食堂人多，先躺了一会儿，打算错峰再去。
```

### 改 L3 例子

在 `THREAD_SYSTEM` 里找：

```text
例一：
例二：
例三：
```

直接替换正文。  
不用改代码结构。

### 改完检查

```text
1. 例子是不是真事
2. 有没有把「他说的」写成「别人说的」
3. 有没有漏掉关键限定
4. 有没有为了短删掉真正重要的部分
5. 有没有连续「主人说……我说……」
```
